# Neovim command-index attribution

`neovim.json` is an extracted and reorganized reference derived from the installed
Neovim 0.12.5 `runtime/doc/index.txt` on September 7, 2026. It retains factual
command notation, help tags and brief action descriptions, with source line
numbers. It is not the complete manual. The collector adds planning conditions
and separates this source from configured mappings.

The Vim user manual and reference manual are Copyright (c) 1988 by Bram
Moolenaar. The documentation is distributed under the
[Open Publication License, version 1.0 or later](https://opencontent.org/openpub/).
The installed copyright statement is `runtime/doc/usr_01.txt`, section 01.4
(`:help manual-copyright`).

Original source: [Neovim's command index](https://neovim.io/doc/user/vimindex.html).
The source checksum recorded in `neovim.json` identifies the installed revision
used for this extraction; the online manual may describe a later version.
